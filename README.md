# WHYNOT

**Your wedding. Your way.**

WHYNOT is the destination-wedding platform concept by **Maldives International Group Pvt Ltd (MIG)**, formerly Maldives Wedding Hub.

Plan the celebration, coordinate guests and connect venues, vendors, accommodation and transfers in one workspace.

## Current status

**Product definition / pre-implementation.** This repository contains the brand and development blueprint. It does not yet contain a running application, authentication service, payment integration or production deployment.

The GitHub repository identifier remains `GITCHAT10/mig-wedding-hub`; WHYNOT is the product name. Repository rename and privacy settings require a separate GitHub administration change.

## Planned experiences

| Workspace | Planned functions |
| --- | --- |
| Couples | Wedding page, planning checklist, budget, vendor shortlist, quotes and seating |
| Guests | Private invitations, household RSVP, dietary/accessibility requests and calendar downloads |
| Vendors | Listings, availability, proposals, milestones and fulfilment updates |
| Coordinators | Event timeline, guest arrangements, supplier follow-up and exception handling |
| MIG operations | Approved integration with Brain Coral for procurement, finance and hospitality coordination |
